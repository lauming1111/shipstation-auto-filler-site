How to use it

From unpacked extension to a completed order.

01

Load it in Chrome

Open chrome://extensions, enable Developer mode, choose Load unpacked, and select the project folder.

02

Open an order

Sign in to ShipStation and open an order detail page. The customs card appears at the right; the toolbar icon can reopen it.

03

Enter parcel details

Select the item type, then add weight and L × W × H. The extension detects order quantity and prepares the declaration.

04

Review, then act

Use Auto Fill to populate the page. Confirm every field and resolve any warning before saving or creating a label.

FAQ

Common questions

Is this available in the Chrome Web Store?

Not currently. This is an active testing release distributed as an unpacked Chrome extension and loaded locally from its project folder.

Does it create labels automatically?

No. It can prepare customs data and guide the workflow, but creating a label remains a deliberate action. Relevant conditions are checked before that step.

Which sites does it support?

The core workflow runs on ShipStation. It also supports selected-order migration from the Yami seller portal and a recipient-first Chit Chats workflow.

Where do credentials go?

Credentials are entered by the operator for their own accounts. When API settings are used, the extension stores them encrypted at rest in the Chrome profile and does not display saved values.

What should I do after changing the extension?

At chrome://extensions, reload the unpacked extension first. Then hard-refresh the target site tab. Reloading only the page may keep an older extension build active.
