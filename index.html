What it helps with

Built around the moments where shipping data goes wrong.

The extension stays in the browser alongside the systems your team already uses. No server, no separate dashboard, and no manual copy-and-paste loop.

↻

Customs, filled consistently

Choose an item type and enter parcel measurements. The in-page card fills the customs description, HS code, item value, quantity, weight, and dimensions on the ShipStation order.

✓

Deliberate safety checks

Address issues, missing services, Canadian destinations, and high live rates are surfaced before a label is created—so the operator stays in control.

→

Order migration support

Move selected Yami orders into ShipStation or begin a Chit Chats shipment, reducing repeated recipient entry while leaving shipping choices to the operator.

How to use it

From unpacked extension to a completed order.

01

Load it in Chrome

Open chrome://extensions, enable Developer mode, choose Load unpacked, and select the project folder.

02

Open an order

Sign in to ShipStation and open an order detail page. The customs card appears at the right; the toolbar icon can reopen it.

03

Enter parcel details

Select the item type, then add weight and L × W × H. The extension detects the order quantity and prepares the declaration.

04

Review, then act

Use Auto Fill to populate the page. Confirm every field and resolve any warning before you save an order or create a label.

FAQ

Common questions

Is this available in the Chrome Web Store?

Not currently. This is an active testing release distributed as an unpacked Chrome extension. It is loaded locally from its project folder.

Does it create labels automatically?

No. It can prepare customs data and help guide the workflow, but creating a label remains a deliberate action. The extension checks relevant conditions and asks for confirmation when appropriate.

Which sites does it support?

The core workflow runs on ShipStation. It also supports selected-order migration from the Yami seller portal and a recipient-first Chit Chats workflow.

Where do my credentials go?

Credentials are entered by the operator for their own accounts. When API settings are used, the extension stores them encrypted at rest in the Chrome profile and the settings screen does not display saved values.

What should I do after changing the extension?

At chrome://extensions, reload the unpacked extension first. Then hard-refresh the target site tab. Reloading only the page may keep an older extension build active.
